# EnvNode FullSize SMD Module Template

This KiCad project is the 38 mm × 64 mm starting point for a Revision 0.2 FullSize daughterboard with a bottom-mounted SMD module connector.

Copy the complete directory when starting a module. Do not add application circuitry to the template itself. Preserve the 2 × 7 connector mapping, connector axis 6.35 mm from the top edge, 2.7 mm M2.5 support holes at 27 mm and 59 mm, and the reference module-identification EEPROM circuit.

See the [module-interface hardware specification](../../../../../docs/EnvNode_Module_Interface_Hardware_Specification.md) and rerun ERC and DRC on every derived board.
