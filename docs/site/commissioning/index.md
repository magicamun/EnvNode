# Inbetriebnahme

Deine Hardware ist aufgebaut und elektrisch geprüft. Hier findest du den Weg
zur Einrichtung mit der Firmware und zum ersten überprüften Ergebnis.

| Was möchtest du einrichten? | Anleitung |
| --- | --- |
| EnvNode zum ersten Mal mit dem Netzwerk verbinden | [Gerät und Netzwerk einrichten](../firmware/configuration.md) |
| Board Identity oder Modulidentität zuordnen | [Hardware und Provisioning](../firmware/provisioning.md) |
| BME280, SHT4x oder SHTC3 | [I²C-Sensoren](i2c-sensors.md) |
| AM2302 / DHT22 | [Sensorformular und GPIO-Auswahl](../firmware/sensors.md) |
| Niederschlag mit einer Kippwaage | [Regenwippe](rain-gauge.md) |
| Benetzung und Trockenheizung | [RainDetector](rain-detector.md) |
| Wechselstrom mit SCT013 | [SCT013 einrichten und prüfen](../sensors/sct013/commissioning.md) |
| Zwei Relaisausgänge | [DuoRelay](../modules/duo-relay/commissioning.md) |
| Messwerte am Gerät anzeigen | [Displays einrichten](../firmware/values-displays.md#displays) |
| Prüf- und Provisioninghardware | [Separate Test-Firmware](../firmware/test-provisioning/inbetriebnahme.md) |

Die Links führen jeweils zur maßgeblichen Anleitung. Gemeinsame Bedienelemente
beschreibt die [Firmware-Anleitung](../firmware/index.md); Bestückung und elektrische
Prüfungen findest du unter [Aufbauanleitungen](../guides/index.md).
