# EnvNode Mini 0.9.0

Zwei Modulslots, vier I²C-Anschlüsse (J7/J8 auf I2C0, J9/J10 auf I2C1) und zwei ADC-Eingänge. Neu: TP1-Testreferenzen, steckbare Pull-ups J3-J6 und C2 für das EEPROM.

[Die vollständige Dokumentation](index.md) enthält Teileliste, Pinbelegung, Löt-Reihenfolge, spannungsfreie Prüfung, Erstinbetriebnahme und Messprotokoll.
