# Weatherstation 0.3.0

Ein Modulslot, acht I²C-Anschlüsse und zehn ADC-/GPIO-Anschlüsse. Neu: TP1-Testreferenzen, steckbare Pull-ups J2-J5 und C2 für das EEPROM.

[Die vollständige Dokumentation](index.md) enthält Teileliste, Pinbelegung, Löt-Reihenfolge, spannungsfreie Prüfung, Erstinbetriebnahme und Messprotokoll.
