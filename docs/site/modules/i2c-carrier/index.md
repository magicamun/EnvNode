# I²C Carrier HalfSize

Der Carrier stellt einem aufgesetzten I²C-Sensor die Modulanschlüsse bereit.
Er ist eine passive Trägerplatine und hat keinen eigenen Sensortreiber.

## Was möchtest du tun?

| Dein Ausgangspunkt | Hier geht es weiter |
| --- | --- |
| Carrier aufbauen, Jumper und Belegung prüfen | [Technische Aufbauanleitung](assembly.md) |
| Einen Sensor auf dem Carrier einrichten | [I²C-Sensor in Betrieb nehmen](../../commissioning/i2c-sensors.md) |
| Prüfen, welcher Sensor unterstützt wird | [I²C-Sensorhardware und Treiber](../../sensors/i2c.md) |

Für die Firmware zählt der tatsächlich aufgesetzte Sensor mit seinem Bus und
seiner Adresse. Ein Carrier allein erzeugt keine Messwerte.
