Sensor-, Aktor- und Controller-Slots lassen sich unter **Konfigurieren** per
Bestätigung zurücksetzen. Beim Sensor nennt die Fehlermeldung eine bestehende
Zuordnung als Temperaturquelle für den Meereshöhendruck oder den abhängigen
Controller mit Nummer und Name.

Unter **Values → MQTT** zeigt jede Value-Karte das Befehlstopic, eine
Beispiel-Payload und das separate Statustopic.

Die Sensor-Konfiguration blendet unpassende Felder bereits im ausgelieferten
HTML aus. Wenn beim Seitenversand drei Sekunden lang keine Daten mehr angenommen
werden, gibt der Webserver die Verbindung für den nächsten Aufruf frei. Das
Diagnoseprotokoll erfasst dabei den letzten Socket-Fehler.
